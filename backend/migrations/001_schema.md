# 001 初始表结构

应用首次启动以 SQLAlchemy 模型创建表与唯一约束。现有数据表只补建缺失表，升级到修改过字段的版本需要显式迁移。

- `users` 账号角色和加盐密码摘要。
- `datasets` 不可变记录批次，以名称和 SHA-256 去重。
- `runs` 记录参数、数据批次、运行租约、分析结果、导出文件及复核决定。
  - `progress`（JSON）为未测项补全核算的逐组检查点，含冻结指纹（批次、组员、切线的 SHA-256）、已完成单元与补全结论；启动时对旧库以 `ALTER TABLE` 补建该列。
- `schedules` 保存定时计划和下一到期时间。
- `deliveries` 保存站内分发回执，每次运行最多一个回执，重试按 `run_id` 去重。
- `audit_events` 记录登录、数据入库、运行、检查点、复核和报表分发动作。
